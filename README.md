# GreenNest Plant Shopping Website

## Requirements
- XAMPP
- VS Code
- Web browser

## Setup
1. Copy this folder to `C:\xampp\htdocs\Plant-Shopping-Website`
2. Start Apache in XAMPP.
3. Open `http://localhost/Plant-Shopping-Website/`
4. Optional database setup: open phpMyAdmin and import `database/plant_shop.sql`.

## Pages
Home, Products, Cart, Checkout, Login, Register, About, Admin Dashboard.

## Note
The current demo uses localStorage for the cart and demo JavaScript login/order actions. The SQL schema is included so you can extend it to a full PHP/MySQL authentication and order system.
